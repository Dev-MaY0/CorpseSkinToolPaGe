# プレイヤーの死体アドオン

プレイヤーが死ぬと、その場に寝転がった死体が残ります。アイテムは通常どおりドロップします（死体は見た目だけ）。

## パック構成

| パック | 役割 | 必須 |
|---|---|---|
| プレイヤーの死体 BP | 死体を出す本体（登録PNG / スティーブ / アレックスで表示） | ○ |
| プレイヤーの死体 RP | 死体のモデル・テクスチャ（BPを入れると自動で入る） | ○ |
| プレイヤーの死体 スキンコピー拡張 (Beta) | 死体を **本人のスキン** で表示する | 任意 |

## 導入

スキンの種類で方法が変わります。両方を同時に使ってもOKです。

| スキン | 方法 | 実験的機能 |
|---|---|---|
| PNG（クラシック）スキン | 下の「Web版」か「スキン登録アプリ」で登録 → 「プレイヤーの死体 BP」を追加 | 不要 |
| キャラクタークリエイター製 | 「ベータ API」を ON → 「スキンコピー拡張 (Beta)」を追加（本体BPとRPも自動で入る） | 必要 |

どちらもしていない人の死体はスティーブ（拡張ありで細腕ならアレックス）になります。

## キャラクタークリエイター製スキン（スキンコピー拡張）のしくみ

- スクリプトAPI（`@minecraft/server-gametest`）の `getPlayerSkin` で死んだ瞬間のスキンを取得し、同じスキンの偽プレイヤー（SimulatedPlayer）を寝かせて表示します。
- 偽プレイヤーは **死体の近く（64ブロック以内）に誰かいる間だけ** 出します。離れると片付けて通常モデルに戻ります。
- `getPlayerSkin` は PNG スキンの画像を返さないため、PNG スキンの人は Web版かスキン登録アプリで登録してください。
  自分のスキンがこちらに対応しているかは `/scriptevent corpse:skin` で確認できます。
- 偽プレイヤーはプレイヤー一覧に「〇〇の死体」として表示され、`@a` にも含まれます。
- 「ベータ API」を ON にしたワールドでは実績が解除されなくなります。

## PNG（クラシック）スキンを死体に出す：Web版（おすすめ）

`web/index.html` は、ブラウザだけで動くスキン登録ページです。インストール不要で、パソコンでもスマホでも使えます。

1. ユーザー名を入れて「スキンをさがす」
2. 必要なら「死体が消えるまで」（初期: 消えない）と「1人あたりの死体」（初期: 10体まで）を選ぶ
3. 「アドオンをダウンロード（.mcaddon）」を押す
4. ダウンロードした `PlayerCorpse_月-日_時-分.mcaddon` をひらく → Minecraft に読み込まれる
5. ワールドの「編集」→「ビヘイビアパック」で「プレイヤーの死体 BP【月/日 時:分版】」を有効にする

作ったアドオンには、Minecraft の中の名前の最後に **【作った日時版】** が付きます（例: `プレイヤーの死体 BP【10/09 14:05版】`）。いちばん新しい日時のものが最新です。
作り直すたびに Minecraft の中に新しい版が増えていく（古い版は自動では消えない）ので、新しいファイルをひらく前に
Minecraft の「設定」→「ストレージ」→「ビヘイビアパック」「リソースパック」で「プレイヤーの死体」で始まるものを削除しておくとスッキリします。

- `index.html` をダブルクリックしてファイルとして直接ひらくと、**ユーザー名での検索ができません**（GeyserMC がファイルからの通信を受け付けないため）。必ず Web サイトに置いてひらいてください。PNG画像からの登録とダウンロードはそのままでも使えます。
- 昔のスキンが表示された人は、一覧でその人を選んで「画像で差し替え」から今のスキンのPNGに差し替えられます（「全員のスキンを取り直す」でも上書きされません。戻すときは「自動取得に戻す」）。腕の太さもその場で切り替えられます。
- 登録した人とスキン画像は、そのブラウザの中にだけ保存されます。
- アドオンのフォルダ（`config.js` など）を書き換えたときは、`web/build_web.ps1` を実行すると `index.html` が作り直されます。

## PNG（クラシック）スキンを死体に出す：スキン登録アプリ

`PlayerCorpseSkinTool.exe` をダブルクリックするだけで使えるアプリです。Windows 10 / 11 に最初から入っている機能（.NET Framework 4.8）で動くので、インストールは要りません。シングルプレイでも使えます。

1. **①** の欄に Minecraft のユーザー名を入れて「スキンをさがす」（Enter でもOK）
2. **②** の緑のボタン「アドオンを作って Minecraft に入れる」を押す → Minecraft が開いて読み込まれる
3. **③** はじめての時だけ、ワールドの「編集」→「ビヘイビアパック」で「プレイヤーの死体 BP」を有効にする

- 登録した人はカードで表示され、押すと右に全身が出ます。カード右上の × で削除できます（最大10人）。
- スキンを変えたら「全員のスキンを取り直す」→ ② をもう一度押してください。
- 人に渡したいときは ② の「ファイルに保存する」で `.mcaddon` を保存できます。
- **見つからない人**は、統合版から Geyser 対応サーバー（例: `test.geysermc.org` ポート 19132）に一度入ると取れるようになります。手持ちのスキンPNGから登録することもできます。
  くわしくはアプリ右上の「使い方・困ったとき」に書いてあります。
- 頭より下がぜんぶ透明なスキン（キャラクタークリエイター製スキンでよくある）は「頭だけのスキンのようです」と確認が出ます。「はい」で頭だけの死体として使えます。
- ② の下で「死体が消えるまで」「1人あたりの死体」を選べます。作ったアドオンの名前には【作った日時版】が付きます（Web版と同じ）。
- 初回起動で「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください（署名のない個人作成アプリのため）。
- 登録データと作ったアドオンは `%LOCALAPPDATA%\PlayerCorpseSkinTool` に保存されます。
- アプリはアドオン本体を中に持っています。exe をアドオンのフォルダ（`PlayerCorpse_BP` など）と同じ場所に置いた場合は、フォルダ側のファイル（書き換えた `config.js` など）を使ってアドオンを作ります。

登録したプレイヤーは、スキンコピー拡張が入っていても登録画像が優先されます。

### アプリを自分でビルドする

`.exe` をダウンロードできない場合や、改造したい場合は、ソースから作れます（C# / WinForms / .NET Framework 4.8）。

**かんたんな方法（インストール不要）**

1. この zip を展開する（展開前に zip を右クリック →「プロパティ」→「許可する」にチェックしておくと警告が出にくくなります）
2. `SkinToolApp` フォルダの `build.bat` をダブルクリック
3. 「Done!」と出たら、一つ上のフォルダに `PlayerCorpseSkinTool.exe` ができています

Windows に最初から入っている C# コンパイラ（`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）を使います。

**PowerShell 7 を使う方法**

```
pwsh ./SkinToolApp/build.ps1
```

## 設定

- 本体: `PlayerCorpse_BP/scripts/config.js`（消えるまでの時間（初期: 0 = 消えない）、1人あたりの上限（初期: 10）、名前表示、死亡座標の通知、消せる人）
  - 消えるまでの時間と1人あたりの上限は、Web版・アプリの画面でも選べます（選んだ値で `config.js` が書き換わります）
- 拡張: `PlayerCorpse_SkinCopy_BP/scripts/config.js`（偽プレイヤーを出す距離、同時に出す上限、頭上の名前）

## 操作・コマンド

| 操作 | 内容 |
|---|---|
| しゃがみながら死体を叩く | 死体を片付ける（初期設定: 本人か `corpse_admin` タグを持つ人） |
| `/tag @s add corpse_admin` | 誰の死体でも片付けられるようにする |
| `/scriptevent corpse:list` | 読み込まれている死体の一覧 |
| `/scriptevent corpse:clear` | 読み込まれている死体をすべて消す |
| `/scriptevent corpse:skin` | 自分のスキンが本人スキン表示に対応しているか確認（拡張のみ） |

## よくあるトラブル

- **アドオンがいくつも増えて、どれが新しいか分からない**：名前の最後の【月/日 時:分版】が作った日時です。古い版は Minecraft の「設定」→「ストレージ」→「ビヘイビアパック」「リソースパック」で削除できます。ワールドの「ビヘイビアパック」で、いちばん新しい日時の版が有効になっているか確認してください。
- **ふつうのスキンPNGなのに「頭の部分しかない」と出る**：以前の版の判定ミスです（体が服のレイヤーにだけ描かれているスキンなどで起きていました）。今の版では、頭より下に1ドットでも色があれば使えます。

- **「インポートに失敗しました：不明なパックの名前」**：古いスキン登録ツール（1.1.4xxxxx のような大きいバージョン番号を付けていた版）で作ったアドオンです。Minecraft のパックのバージョンは各数字 65535 までのため読み込めません。今の Web版・アプリで作り直してください。
