Bot を Discord サーバーに招待する 近接VCページへ

🔑Discord の Bot のトークンを入れる

  1. Discord Developer Portal をひらいて、右上の「New Application」→ 名前（例: 近接VC）を入れて「Create」
  2. 左のメニューの「Bot」→「Reset Token」→「Yes, do it!」→「Copy」
  3. 下に貼り付けて「設定する」を押す（Bot の URL の登録や、/vc コマンドの登録は自動でやります）

    トークンは、この Worker（あなたの Cloudflare）の中にだけ保存されます。ほかの人には見せないでください。
    Bot を作り直したときや、トークンを Reset したときは、新しいトークンをもう一度入れてください。
    上級者向け: Cloudflare の「設定」→「変数とシークレット」に DISCORD_TOKEN（シークレット）を入れておくと、このページを開くだけで自動で設定されます。
