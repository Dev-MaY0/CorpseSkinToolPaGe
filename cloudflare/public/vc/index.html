近接VC

Minecraft の位置で Discord のVCを自動で切り替え　｜　制作: MaYo（mayo01297）

？ 使い方・困ったとき
🏠 トップ 🪦 死体スキン 🎙 近接VC

⚠ まだ近接VC Bot の設定が終わっていません。サイトを公開した人は、設定ページで Discord の Bot のトークンを入れてください。

⚡ かんたんな流れ（ワールドで遊ぶとき）
  1. ① の「Bot を招待する」を押す
  2. Discord で /vc setup を送る → 届いたファイルをひらく（近接VCアドオンが入ります）
  3. ワールドでチートをオンにして、Discord に出た /wsserver … をチャットに貼る
  4. 遊ぶ人は /vc link で自分の名前を選んで、「🎮 近接VC ロビー」に入る

Discord のメッセージの「サイトでくわしく見る」ボタンから来ると、接続キーが自動で入ります。下の手順は、くわしく知りたいとき・BDS で使うときに。

🎙近接VCでできること

  • Minecraft で近くにいるプレイヤーの声だけ聞こえる（近い人どうしを Discord の同じVCに自動で移動）
  • 離れると別のVCに分かれて、一定の距離で聞こえなくなる（声が届く距離は /vc distance で設定）
  • プレイヤーが死んだら死亡者専用VCへ（死亡者どうしだけで話せる。リスポーンすると元に戻る）
  • Discord のユーザーと Minecraft のプレイヤーを紐付ける
  • 専用の Discord Bot で、VCの参加者を管理（だれがどこにいるか・紐付け・リセット）

※ Discord のVCを切り替える方式のため、距離に合わせて声の大きさを少しずつ変えることはできません（Discord の仕様）。近い人どうしは同じVC、離れると別のVC、という切り替えになります。

1Bot を Discord サーバーに招待する

Bot を招待する

サーバーの管理者がやってください。Bot には「チャンネルの管理」「メンバーを移動」「接続」などの権限が必要です（招待のときに自動でつきます）。

2Discord で /vc setup を送る

Bot が「🎮 近接VC ロビー」「💀 死亡者VC」「🔊 近接VC 1〜4」を自動で作って、ワールド用の近接VCアドオンと /wsserver のコマンドを送ってくれます（自分にだけ見えるメッセージ）。
メッセージの「サイトでくわしく見る」ボタンを押すと、このページに接続キーが自動で入ります。

3近接VCアドオンを作る

接続キー

遊ぶ場所

ワールド用は、接続キーがなくても作れます。BDS用は接続キーが入ったアドオンになります。

Discord の /vc setup や /vc addon でも、同じアドオンがもらえます。
作り直したときは、Minecraft の「設定」→「ストレージ」→「ビヘイビアパック」で古い「近接VC BP」を消してから入れるとスッキリします（名前の最後に作った日時が付きます）。

4ゲームと Discord をつなぐ

だれかのワールド（ホストがやること・ワールドを開くたびに）

  1. ワールドの設定で「チートを有効にする」をオン、「ビヘイビアパック」で「近接VC BP」を有効にする
  2. ワールドを開いて、チャットにこのコマンドを貼り付けて送る
    （接続キーを入れると、ここにコマンドが出ます）

    「サーバーに接続できませんでした」と出るときは、接続チェックをひらいたまま、もう一度送ってください（どこで止まっているか分かります）。

  3. チャットに「[近接VC] Discord「サーバー名」とつながりました」と出たら準備OK

ホストがワールドを閉じると、全員「🎮 近接VC ロビー」に戻ります。

BDS・レンタルサーバー（サーバーの管理者がやること・最初の1回だけ）

  1. ③ で作った「近接VC BP」を、サーバーのワールドにビヘイビアパックとして入れる（入れ方はサーバーによってちがいます。world_behavior_packs.json に書くときは下の内容） 
    （BDS用をダウンロードすると、ここに出ます）
  2. ワールドの実験的機能「ベータ API」をオンにする（BDS で HTTP 通信を使うのに必要です）
  3. config/default/permissions.json を次の内容にする（@minecraft/server-net を使えるようにする） 
    {
  "allowed_modules": [
    "@minecraft/server-gametest",
    "@minecraft/server",
    "@minecraft/server-ui",
    "@minecraft/server-admin",
    "@minecraft/server-editor",
    "@minecraft/server-net"
  ]
}
  4. サーバーを再起動する。つながらないときは、チャットに「[近接VC] Discord の Bot につながりません」と出ます

サーバーが止まると、1分後に全員「🎮 近接VC ロビー」に戻ります。

5遊ぶ人みんながやること

  1. Discord で /vc link を送る（最初の1回だけ）。ゲーム中なら、自分の名前が候補に出るので選ぶだけ
  2. 紐付けを確かめる
    • ワールド: マイクラのチャットで、Bot に言われたとおり !vc 1234 のように送る
    • BDS: ゲームの中に確認画面が出るので「紐付ける」を押す
  3. 遊ぶときは Discord の「🎮 近接VC ロビー」に入っておく → ゲームの中の位置で、自動でVCが切り替わります（数秒かかることがあります）
  4. 死んだら「💀 死亡者VC」へ。リスポーンすると、近くの人のVCに戻ります

/Bot のコマンド

コマンドできること
/vc setup 管理者近接VC用のVCを作って、接続キーを出す（もう一度やっても作り直しません）
/vc link みんな自分の Discord とマイクラのアカウントを紐付ける（ゲーム中の人は名前が候補に出る）
/vc unlink みんな紐付けを外す（管理者は、ほかの人の紐付けも外せる）
/vc status みんなつながっているか・だれがどのVCにいるか・紐付けていない人を見る
/vc distance 管理者声が届く距離（4〜128ブロック、ふだんは20）を変える
/vc reset 管理者全員をロビーに戻す
/vc addon みんな近接VCアドオンのファイルをもらう（BDS用は管理者だけ）
/vc key 管理者/wsserver のコマンドと接続キーをもう一度見る
/vc rekey 管理者接続キーと接続コードを作り直す（人に見られたとき）
？ 使い方・困ったとき

■ /wsserver でつながらない（「サーバーに接続できませんでした」）

  • まず 接続チェック（④ のリンク、または Discord の「接続チェック」ボタン）をひらいたまま、コマンドを送ってください。Bot まで届いたかどうかが、その場で分かります。
  • ワールドのチートがオンになっているか確認してください（ホストがオペレーター権限を持っている必要があります）。
  • 「設定」→「一般」の WebSocket の項目：「WebSocket を有効にする」のようなスイッチがあればオン、「暗号化された WebSocket を要求」はオフにして、Minecraft を一度終了してからひらき直してください。
  • コマンドの ws:// を wss:// に変えると、つながることがあります。
  • 学校などの Wi-Fi や、セキュリティソフトの「Web保護」が止めていることがあります。スマホのテザリングなど、ちがう回線でも試してください。
  • Discord で /vc rekey をした後は、新しいコマンド（接続コードが変わります）を使ってください（/vc key で見られます）。

■ VCが切り替わらない

  • Discord で /vc status を送ると、だれがどうなっているか見られます。
  • 「VCに入っていません」→ 先に「🎮 近接VC ロビー」に入ってください。Bot は、VCに入っていない人を動かせません。
  • 「近接VC以外のVCにいます」→ 近接VCとは関係ないVCにいる人は、勝手に動かしません。ロビーに移ってください。
  • 「ゲームにいるけど紐付けていない人」に名前があったら、その人は /vc link をしてください。
  • Bot の役職（ロール）に「メンバーを移動」の権限があるか確認してください。

■ 死亡者VCについて

死んだ人は「💀 死亡者VC」に移動して、死亡者どうしだけで話せます。生きている人には聞こえません。リスポーンすると、近くの人のVCに戻ります。

■ 近接VCの数が足りない・増えた

グループが増えると「🔊 近接VC 5」「6」… と自動で作ります（最大30）。

■ 声の大きさが距離で変わらない

Discord の Bot は、ほかの人の声の大きさを変えられないため、「近い人どうしは同じVC・離れたら別のVC」という方式です。声が届く距離は /vc distance で変えられます。

■ データについて

アドオンが Bot に送るのは「だれとだれが同じグループか（部屋の番号）」だけで、座標は送りません。Bot（Cloudflare）には、Discord のユーザーIDと名前・マイクラの名前・紐付け・接続キーが保存されます。
